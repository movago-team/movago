# Movago

เทมเพลตพื้นฐานสำหรับทดสอบเท่านั้น

## ความต้องการ

- Node.js 18+

## เริ่มต้น

```bash
cd movago
npm install
npm run dev
```

เปิดที่ `http://localhost:5173`

## สคริปต์

| คำสั่ง | คำอธิบาย |
| --- | --- |
| `npm run dev` | รันเซิร์ฟเวอร์พัฒนา |
| `npm run build` | สร้างไฟล์ production |
| `npm run preview` | ดูผลหลัง build |
